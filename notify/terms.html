2. DESCRIPCIÓN DEL SERVICIO

2.1. Notify App es un sistema de alertas y notificaciones que utiliza la API de WhatsApp para enviar mensajes relacionados con sistemas domóticos a nuestros clientes.

2.2. El Servicio está diseñado para proporcionar notificaciones oportunas y relevantes sobre el estado y funcionamiento de los sistemas domóticos de nuestros clientes.

2.3. Las notificaciones se envían a través de WhatsApp, utilizando el número proporcionado por el cliente durante el registro.
